# Obsidian Web Clipper Inbox

ตั้งค่า Obsidian Web Clipper ให้บันทึกบทความไว้ที่:

`03-source-materials/web-clips/`

กติกาของโฟลเดอร์นี้:

- ไฟล์ที่ clip เข้ามาเป็น source snapshot แบบ read-only
- หลังบันทึกแล้วห้ามแก้หรือลบต้นฉบับในที่เดิม หากต้องแก้ให้สร้างไฟล์หรือเวอร์ชันใหม่
- รูปและไฟล์แนบให้เก็บใน `03-source-materials/assets/`
- เมื่อต้องการสรุปหรือเชื่อมความรู้ ให้สร้างหน้าสรุปแยกใน
  `01-knowledge-base/sources/` โดยไม่แก้ source ต้นฉบับ
- ห้าม clip credential, token, session data, ข้อมูลผู้ป่วย หรือข้อมูล production
  ที่เป็นความลับเข้ามาใน Vault
