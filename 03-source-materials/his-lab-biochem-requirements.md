## หน่วยงานชีวเคมี

### ❖ โมดูลไหนที่ไม่ได้ใช้งาน  _(ไฮไลต์เหลือง)_

- 3.4.4.1 รายการแสดงของผู้ป่วยนัด `(LAB)`
- 3.4.4.3 รายการแสดงของผู้ป่วยส่งต่อ `(LAB)`
- 3.4.4.10 สามารถส่ง Order Work List ไประบบ List สามารถส่งทั้งหมดได้โดยกดครั้งเดียว `(LAB)`
- 3.4.4.11 สามารถประสาน IT out lab (PCT lab) โดยสร้างรายละเอียดการส่ง order
  และการรับผลกลับเข้าระบบ (File รูปภาพ) `(LAB)`

### ❖ โมดูลที่ใช้งานแต่ไม่มีในข้อมูลข้างต้น  _(ไฮไลต์ฟ้า)_

1. Lab Reuest Monitoring  _[sic — Lab Request Monitoring]_
2. สถานะการสั่งแลป
3. ข้อมูลห้องแลป
4. บันทึกความเสี่ยง(หน่วยงาน)

### ❖ สิ่งที่อยากให้ **เพิ่ม** หรือ **แก้ไข** จาก HIS ในปัจจุบัน  _(ไฮไลต์เขียว)_

1. รายการสั่งตรวจ LAB ของผู้ป่วยที่แพทย์ order ไว้ล่วงหน้า เมื่อถึงวันที่นัดต้องการให้มีข้อมูล
   รายการตรวจมาหน้าจอ **"รอรับเข้าดำเนินการ"** แบบอัตโนมัติ

2. การสร้างออร์เดอร์ LAB แก้ไขเป็นการเลือกรายการตรวจ **แบบติ๊กรายการตรวจ** ไม่ใช่การเสริทเลือก
   ทีละรายการ และ **จัดเรียงรายการตรวจตามรูปแบบของใบส่งตรวจ**

3. หน้าต่างการทำงานหลักของห้อง LAB สามารถแยกสถานะ **การรอรับเข้า / รับเข้าดำเนินการ /
   ออกผลแล้ว** อย่างชัดเจน

4. **หน้ารอรับเข้า**
   - สามารถปรับปรุงแก้ไข ลบ รายการตรวจ
   - ปรับเปลี่ยน LAB NO.
   - สามารถตรับ LAB โดยบันทึกเวลาที่รับ LAB _[sic — "รับ LAB"]_ สามารถปฏิเสธสิ่งส่งตรวจ
     พร้อมใส่เหตุผลและชื่อผู้ปฏิเสธได้
   - สามารถตรวจสอบสิทธิการรักษา สถานะการชำระเงิน
   - พิมพ์ใบสั่งตรวจได้

5. **หน้าออกผลแล้ว**
   - แสดงผลการตรวจ / Comment ต่างๆ / ค่า Ref.Range โดยยึดลำดับรายการตาม Report LIS
   - มีการแจ้งเตือนค่าวิกฤติที่ชัดเจน ในระดับ order ละ แต่ละรายการตรวจ
   - สามารถแก้ไข หรือ ปกปิด ผลการตรวจได้ในหน้าดูผลการตรวจ
   - สามารพิมพ์ผลการตรวจได้ _[sic]_

6. มีหน้าต่างที่สามารถลงผลการตรวจโดยวิธี **Manual** และออกผลแสดงบน HIS ได้ กรณี **LIS ล่ม**
   หรือไม่สามารถใช้งานได้ และสามารถพิมพ์ผลได้

7. สามารถเข้าถึงข้อมูลส่วนบุคคลพื้นฐานของผู้ป่วยได้ เช่น ชื่อ-สกุล (มี Remark กรณีผู้ป่วยเปลี่ยน
   ชื่อ-สกุลใหม่) เพื่อเป็นการตรวจสอบความถูก ว/ด/ป เกิด รหัสบัตร ปชช ช่องทางการติดต่อผู้ป่วย
   ที่อยู่ เบอร์โทรศัพท์ บุคคลที่สามารถติดต่อได้ สิทธิการรักษา สถานะของผู้ป่วยว่า Check in หรือ
   Admit ที่ไหน ข้อมูลรายการนัดครั้งต่อไป

8. **หน้าจอดูผลการตรวจสำหรับแพทย์** เมนูเดิม **"สถานะการสั่งแลป"**
   - แสดงผลการตรวจ / Comment ต่างๆ / ค่า Ref. Range โดยยึดลำดับรายการตาม Report LIS และใน
     รายการที่รอการออกผลหรือกรณีที่ออกผลแล้วบางส่วน รายการที่เหลืออยากให้ขึ้นสถานะ
     **pending (รอผล)** เพื่อป้องกันการเข้าใจผิดว่าไม่ได้สั่งตรวจ
   - <u>กรณีผลค่าวิกฤติ</u> มีการแจ้งเตือนค่าวิกฤติตรง **LAB NO.** ให้แพทย์เห็นอย่างชัดเจน
   - เมื่อพิมพ์ผลควรระบุ **"สำเนาพิมพ์ออนไลน์"** ระบุชื่อผู้พิมพ์ / วันและเวลาที่พิมพ์ เพื่อความชัดเจน
     ในการอ้างอิงข้อมูล เนื่องจากการพิมพ์ออนไลน์ถือเป็นเอกสารสำเนาที่ใช้ในการดูแลรักษาเบื้องต้น
     ในหอผู้ป่วย (หากต้องการใช้เพื่อวัตถุประสงค์ทางกฎหมายหรือส่งต่อภายนอก ควรใช้ฉบับจริงที่มี
     ลายเซ็นรับรองจากนักเทคนิคการแพทย์)
   - กรณีพิมพ์ผลหากผลมีมากกว่า 1 หน้า ควรมีการระบุ **page 1/2** ในใบ report

9. **รายงาน (LAB)**
   - สรุปรายงานสถิติรายการตรวจวิเคราะห์ทั้งหมด ประจำเดือนตามวันและเวลาต่างๆ แยกตาม **Ward**
     และ **Clinic** และ Export ออกมาเป็น File Excel ได้
   - สรุปสถิติจำนวน Order (ตาม LAB NO. ที่ออกผล) ทั้งหมดรายเดือนตามวันและเวลาต่างๆ
     แยกตาม Ward และ Clinic และ Export ออกมาเป็น File Excel ได้
   - สรุปจำนวนการส่งตรวจตาม **Specimen type** ทั้งหมดรายเดือนตามวันและเวลาต่างๆ
     แยกตาม Ward และ Clinic และ Export ออกมาเป็น File Excel ได้
   - สามารถสืบค้นผลการตรวจวิเคราะห์ โดยการกำหนดรายการตรวจ และเลือก**ค่าช่วงผลการตรวจ**
     ที่ต้องการได้ และ Export ออกมาเป็น File Excel ได้

10. เมนูเดิม **"บันทึกความเสี่ยง(หน่วยงาน)"** สามารถดึงข้อมูลรายงานความเสี่ยง
    การปฏิเสธสิ่งส่งตรวจ และ Export ออกมาตามแบบฟอร์มได้

11. เมนูเดิม **"ข้อมูลห้องแลป"**
    - สามารถเพิ่ม comment เหตุผลการปฏิเสธสิ่งส่งตรวจได้
    - สามารถตรวจสอบ ข้อมูล code รายการตรวจ ที่ HIS ส่งมายัง LIS
    - สามารถตรวจสอบ ข้อมูลราคาต่อหน่วย ราคาเบิกได้ ของรายการตรวจวิเคราะห์ได้
      โดยแยกตามสิทธิต่างๆ
