## สถานะปัจจุบัน

| widget | render ตอน import โดยไม่คลิกอะไร |
|---|---|

| `file-upload-input` (ที่ root) | ✅ ยืนยันแล้ว |

## 🔴 อ่านตรงนี้ก่อน — หลักฐานเก่าเชื่อไม่ได้

ระหว่างเคสนี้เคยสรุปไป 2 ครั้งว่า `list-ui` "ขึ้นแล้ว" **ทั้งสองครั้งผิด** เพราะภาพหน้าจอที่ใช้ตัดสิน
มี widget ถูกเลือกอยู่ ซึ่งการเลือกทำให้ canvas re-render แล้ว widget โผล่ — เป็นอาการของบั๊กนี้พอดี

> **กติกาการอ่านผลที่ถูกต้อง**: ภาพต้องถ่ายทันทีหลัง import โดย **ไม่คลิกอะไรเลย**
> และ Property panel ต้องแสดง **Form Setting** (แปลว่าไม่มีอะไรถูกเลือก)
> ถ้า Property แสดงชื่อ widget หรือ Grid Col = ภาพนั้นใช้เป็นหลักฐานไม่ได้

ผลที่ตามมา: ข้อสรุปที่ว่า "`key` บน `list-ui` คือสาเหตุ" **ยังไม่ถือว่าพิสูจน์แล้ว** —
ยังเก็บกฎไว้เพราะแม่แบบทั้ง 5 ตัวไม่มี `key` จริง (หลัก "ทำให้เหมือนแม่แบบ") แต่ห้ามอ้างว่าเป็นสาเหตุ

## งานถัดไป — ทำตามลำดับ ห้ามข้าม

### ขั้นที่ 1 · ทดสอบ baseline (ถูกที่สุด และอาจจบเคสได้เลย)

ให้ผู้ใช้ import **`Lab_Result_Inbound_Receive_User_View_EMR_Person_v2.json`** ซึ่งเป็นฟอร์มที่ระบบ
export มาเองและมี `list-ui` อยู่ข้างใน **โดยไม่แก้อะไรเลยสักตัวอักษร** แล้วดูทันทีโดยไม่คลิกอะไร

- **ถ้า `list-ui` ของมันก็ไม่ขึ้นเหมือนกัน** → นี่คือ**พฤติกรรมปกติของ Builder** ไม่ใช่บั๊กของไฟล์เรา
  `list-ui` เป็น `display_ui` ที่ต้องดึงข้อมูล Builder อาจไม่ render ในโหมดออกแบบจนกว่าจะคลิก
  → **ปิดเคส** แล้วไปยืนยันที่ **Preview / แอปจริง** แทน ไม่ต้องแก้ JSON อีก
- **ถ้าของมันขึ้น** → เป็นบั๊กของไฟล์เราจริง ไปขั้นที่ 2

### ขั้นที่ 2 · bisect (ทำต่อเมื่อขั้นที่ 1 บอกว่าของแม่แบบขึ้น)

ตั้งต้นจากไฟล์แม่แบบที่ขึ้นได้ แล้วค่อย ๆ เปลี่ยนเข้าหาไฟล์เรา **ทีละอย่าง import ทุกครั้ง**
เรียงจากที่น่าสงสัยน้อยไปมาก:

1. เปลี่ยน `options.name` / `titleName` / `label` ของ `list-ui` เป็นของเรา
2. เปลี่ยน `formId` เป็น `6a7aa641935ed08882467374`
3. เปลี่ยน `where` เป็น `order_status_id = '__NO_CONTEXT__' AND xrstatx NOT IN(0,3)`
4. เปลี่ยน `height` — แม่แบบใช้ `560px` / `680px` / `760px` / `190px` / `550px` ของเราใช้ `600px`
5. ใส่ `customValue[]` 8 รายการของเรา
6. ใส่ `buttonsRow[].onClick` (มี `openForm` และ template string)
7. ใส่ `detailContent` (HTML ที่อ้าง class ใน `cssCode`)
8. ใส่ `customClass: "lab-result-items-list"` + `cssCode` ของฟอร์ม

**ตัวที่ทำให้พังคือตัวแรกที่ import แล้ว list หาย** — บันทึกลง `SDFORM_JSON_RULES.md` ทันที
พร้อมหลักฐาน (ภาพที่ Property เป็น Form Setting)
