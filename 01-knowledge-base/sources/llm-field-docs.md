## Key takeaways
- The client talks to the server exclusively through the **`userState` connector** (`runProcess` / `crud*` / `api*`) — the bridge to [[server-api-app]].
- `data.fieldName` is a **reactive** model: reading/writing it in events updates the form live.
- Field names are the universal key — [[xformdatax]] merges back by matching these exact names.
