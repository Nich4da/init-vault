| ข้อความ | แปลว่า |
|---|---|

| `รายการนี้ยังไม่มีเครื่องผูกไว้ใน master` | ไปเติม `xray_item.modality` ที่ item master |

- [ ] ใบเปลี่ยนเป็น **ออกผลครบ** · chip `ออกผลครบ` +1 และ `รอรับ / รอผลอ่าน` −1
      *(ตัวเลข chip กับป้ายในแถวต้องตรงกันเสมอ ถ้าไม่ตรงคือบั๊ก บอกมา)*
- [ ] แท็บ **ผลอ่าน** กดได้ · ปุ่ม **ดูผลอ่าน** โผล่
- [ ] กดดูผลอ่าน → เห็นข้อความเต็ม · เวลาถ่าย = `ImageCapturedDateTime` · รหัสรังสีแพทย์ = `RAD-007`
- [ ] ปุ่ม **PDF** กดได้แล้ว (ยังเป็น placeholder)

## T4 · ผลอ่านหลายฉบับ

ยิง T3 ซ้ำอีกรอบ เปลี่ยนแค่ `ResultText` และ `ResultDateTime` ให้ใหม่กว่า

- [ ] Dialog ขึ้นแถบเหลือง `accession นี้มีผลอ่าน 2 ฉบับ · แสดงฉบับล่าสุด`
- [ ] เนื้อหาที่เห็นคือ**ฉบับใหม่** ไม่ใช่ฉบับแรก

> endpoint ของทีม insert ทุกครั้ง ไม่ upsert — เราเลยหยิบฉบับล่าสุดเองและบอกให้ผู้ใช้รู้

## T5 · ส่งตรวจซ้ำ (เลขเดิม)

ที่รายการซึ่ง **ออกผลแล้ว** ติ๊กแล้วดูปุ่ม

- [ ] ปุ่มเปลี่ยนคำเป็น **ส่งตรวจซ้ำ** (ไม่ใช่ "ส่งเข้าเครื่องใหม่")
- [ ] กดแล้ว **เลข Accession เท่าเดิม** ไม่มีเลขใหม่
- [ ] สถานะกลับไปเป็น **ส่งเครื่องแล้ว** (รอผลรอบใหม่) · เวลาส่งอัปเดตเป็นตอนนี้
- [ ] ที่ฟอร์ม `xray_order` แถวเดิมถูก update ไม่ได้เกิดแถวใหม่
- [ ] ยิงผลรอบใหม่ (T3 ด้วยเวลาใหม่กว่า) → กลับเป็น **ออกผลแล้ว** พร้อมข้อความใหม่

## T6 · ยกเลิก order

**ใบที่ยังไม่มี Accession:**
- [ ] ปุ่ม **ยกเลิก order** กดได้ → dialog บังคับกรอกเหตุผล
- [ ] ไม่กรอกเหตุผล ปุ่มยืนยันกดไม่ได้
- [ ] ยืนยันแล้วทุกรายการเป็น **ยกเลิก** · chip `ยกเลิก` +1
- [ ] แถวที่ยกเลิกแล้ว **EMR หายไป กลายเป็นปุ่ม ตรวจใหม่**
- [ ] กดยกเลิกซ้ำ → บอกว่า "ถูกยกเลิกแล้ว" ไม่ error ไม่เกิดใบซ้ำ

**ใบที่มี Accession แล้ว:**
- [ ] ปุ่มเป็นสีจาง กดไม่ได้ · ชี้เมาส์เห็นเหตุผล
- [ ] ถ้ากดได้ต้องขึ้น `…ออกเลข Accession … ต้องใช้ API ยกเลิกฝั่ง RIS` และ **ไม่มีอะไรเปลี่ยน**
