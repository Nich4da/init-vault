# SDForm Template Backup — Read Only

โฟลเดอร์นี้ใช้เก็บสำเนาต้นแบบ Form Factory/SDForm ที่ผ่านการ export จาก
initCraft แล้ว โดยเก็บเป็นไฟล์ JSON เท่านั้น **ไฟล์ต้นแบบในโฟลเดอร์นี้เป็น
reference snapshot สำหรับเปิดดูหรือคัดลอกออกไปใช้เท่านั้น**

## กฎ Read-only

- ห้ามแก้ไข ลบ เปลี่ยนชื่อ ย้าย หรือเขียนทับไฟล์ต้นแบบที่อยู่ใน `backup/`
- เมื่อต้องสร้าง Form ใหม่ ให้คัดลอกต้นแบบออกไปทำงานภายใต้
  `Form-Builder/SDForm/form-factory/forms/` หรือโฟลเดอร์อื่นภายใต้
  `Form-Builder/SDForm/` ที่ตรงกับชนิดงาน แต่ต้องอยู่นอก `backup/`
- ห้ามใช้ไฟล์ใน `backup/` เป็น working copy โดยตรง
- เพิ่ม snapshot ใหม่ใน `backup/` ได้เฉพาะเมื่อผู้ใช้สั่งให้สำรองหรือเผยแพร่
  ต้นแบบโดยชัดเจน และต้องสร้างเป็นไฟล์เวอร์ชันใหม่โดยไม่แก้ไฟล์เดิม

แนวทางการเก็บไฟล์:

- เก็บต้นแบบที่นำกลับมาใช้ซ้ำได้ โดยต้นฉบับใน `backup/` ต้องคงสภาพเดิม
- ใช้ชื่อแบบ `form-name-template-v1.json` และเพิ่มเลขเวอร์ชันแทนการเขียนทับ
- ลบข้อมูลผู้ป่วย ข้อมูลจริง credential, token และค่าลับก่อนนำมาเก็บ
- ระบุที่มาและสถานะการทดสอบไว้ในชื่อไฟล์หรือเอกสารประกอบ
- ก่อนนำไปใช้ ให้ตรวจด้วย `Form-Builder/seed/tests-tools/validators/check_sdform_json.py`
  และยืนยันอีกครั้งใน Builder/Preview จริง
