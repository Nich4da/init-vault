# Python Seed and Tooling Library

This folder contains the migrated Python artifacts, separated from JSON and
JavaScript while preserving their original category paths.

- `data-imports/` — reference-range and import-data builders
- `draw_design/_gen/` — draw.io generation/rendering helpers
- `tests-tools/scripts/` — SDForm/HIS/LAB builders and maintenance scripts
- `tests-tools/validators/` — `check_sdform_json.py`

Python files inside `02-initcraft/skills/` remain with their skill packages
because moving an executable skill resource would break the skill structure.
