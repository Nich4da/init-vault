# API Template Backup — Read Only

โฟลเดอร์นี้ใช้เก็บสำเนาต้นแบบ API Factory process ที่นำกลับมาใช้ซ้ำได้
โดยเก็บเป็นไฟล์ JavaScript เท่านั้น **ไฟล์ต้นแบบในโฟลเดอร์นี้เป็น reference
snapshot สำหรับเปิดดูหรือคัดลอกออกไปใช้เท่านั้น**

## กฎ Read-only

- ห้ามแก้ไข ลบ เปลี่ยนชื่อ ย้าย หรือเขียนทับไฟล์ต้นแบบที่อยู่ใน `backup/`
- เมื่อต้องสร้าง API process ใหม่ ให้คัดลอกต้นแบบออกไปทำงานภายใต้
  `Form-Builder/API/api-factory/processes/` หรือโฟลเดอร์อื่นภายใต้
  `Form-Builder/API/` ที่ตรงกับชนิดงาน แต่ต้องอยู่นอก `backup/`
- ห้ามใช้ไฟล์ใน `backup/` เป็น working copy โดยตรง
- เพิ่ม snapshot ใหม่ใน `backup/` ได้เฉพาะเมื่อผู้ใช้สั่งให้สำรองหรือเผยแพร่
  ต้นแบบโดยชัดเจน และต้องสร้างเป็นไฟล์เวอร์ชันใหม่โดยไม่แก้ไฟล์เดิม

แนวทางการเก็บไฟล์:

- เก็บต้นแบบที่ผ่านการลบข้อมูลเฉพาะระบบแล้ว โดยต้นฉบับใน `backup/` ต้องคงสภาพเดิม
- ใช้ชื่อแบบ `api-name-template-v1.js` และเพิ่มเลขเวอร์ชันแทนการเขียนทับ
- ห้ามเก็บ credential, token, database URI, `.env` หรือข้อมูลผู้ป่วย/ข้อมูลจริง
- ระบุ params, รูปแบบผลลัพธ์, ที่มา และสถานะการทดสอบไว้ใน comment ส่วนหัว
- ตรวจ syntax และทดสอบใน API Factory ก่อนนำไปใช้งานจริง โดยคำนึงว่า snippet
  บางไฟล์ใช้ top-level `await` ของ runtime initCraft
